## `messages.received` event

Fired when a message is received.

<Note>
  Besides messages received from contacts (`fromMe: false`), this event also
  fires for messages sent by **your own number from another device
  or phone**, with `fromMe: true`. Messages sent through the D-API API trigger the
  [`messages.sent`](/en/whatsapp/webhooks/messages-sent) event, **not**
  `messages.received`.
</Note>

### Payload

<ResponseField name="event" type="string" required>
  Always `"messages.received"`
</ResponseField>

<ResponseField name="sessionId" type="string" required>
  ID of the session that received the message
</ResponseField>

<ResponseField name="timestamp" type="string" required>
  ISO 8601 timestamp of receipt
</ResponseField>

<ResponseField name="traceId" type="string" required>
  Unique ID for tracing
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="data fields">
    <ResponseField name="id" type="string" required>
      Unique message ID
    </ResponseField>
    <ResponseField name="type" type="string" required>
      `text` | `image` | `video` | `audio` | `document` | `sticker` | `contact` | `location` | `reaction` | `edited_message` | `poll_update` | `list_response` | `template_button_reply` | `list` | `carousel` | `nativeflow`
    </ResponseField>
    <ResponseField name="message" type="string" required>
      Text content of the message
    </ResponseField>
    <ResponseField name="timestamp" type="number" required>
      Unix timestamp in milliseconds
    </ResponseField>
    <ResponseField name="fromMe" type="boolean" required>
      Whether the message was sent by you
    </ResponseField>
    <ResponseField name="is_group" type="boolean" required>
      Whether it is a group message
    </ResponseField>
    <ResponseField name="group_name" type="string" required>
      Group name (empty if not a group)
    </ResponseField>
    <ResponseField name="from_name" type="string" required>
      Sender name
    </ResponseField>
    <ResponseField name="media_url" type="string | null" required>
      S3 file URL (for media messages)
    </ResponseField>
    <ResponseField name="from" type="object" required>
      <Expandable title="from fields">
        <ResponseField name="jid" type="string" required>
          WhatsApp ID (e.g. `5511999999999@s.whatsapp.net`)
        </ResponseField>
        <ResponseField name="lid" type="string" required>
          WhatsApp internal ID
        </ResponseField>
        <ResponseField name="name" type="string" required>
          Contact name
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="to" type="object" required>
      <Expandable title="to fields">
        <ResponseField name="jid" type="string" required>
          Recipient's WhatsApp ID
        </ResponseField>
        <ResponseField name="name" type="string" required>
          Recipient name
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="media_data" type="object">
      Present in media messages (image, video, audio, document, sticker)
      <Expandable title="media_data fields">
        <ResponseField name="url" type="string" required>
          Original WhatsApp URL (temporary)
        </ResponseField>
        <ResponseField name="file_length" type="number" required>
          Size in bytes
        </ResponseField>
        <ResponseField name="mimetype" type="string" required>
          File MIME type
        </ResponseField>
        <ResponseField name="width" type="number">
          Width (image/video/sticker)
        </ResponseField>
        <ResponseField name="height" type="number">
          Height (image/video/sticker)
        </ResponseField>
        <ResponseField name="caption" type="string">
          Caption (image/video/document)
        </ResponseField>
        <ResponseField name="duration" type="number">
          Duration in seconds (audio/video)
        </ResponseField>
        <ResponseField name="is_ptt" type="boolean">
          Push-to-talk / voice message (audio)
        </ResponseField>
        <ResponseField name="filename" type="string">
          File name (document)
        </ResponseField>
        <ResponseField name="is_animated" type="boolean">
          Whether it is an animated sticker (sticker)
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="data" type="object">
      Type-specific data for contact, location, reaction, and poll_update
      <Expandable title="ContactData (type=contact)">
        <ResponseField name="contact_name" type="string" required>

        </ResponseField>

        <ResponseField name="degrees_latitude" type="number" required>

          Longitude

        <ResponseField name="name" type="string" required>
          Place name

          Address

        <ResponseField name="thumbnail" type="string" required>

        <ResponseField name="original_message_id" type="string" required>

          Reaction emoji

        <ResponseField name="reaction_timestamp" type="number" required>
          Reaction timestamp

        <ResponseField name="edited_text" type="string" required>
          New message content. It is the same value that arrives in `data.message`.
        </ResponseField>

          Unix timestamp in milliseconds of when the edit was made

          this happens when the edited message predates the session's connection.

        </ResponseField>
        <ResponseField name="original_message_key" type="object">
          Raw reference to the original message, present only in edits
          coming from history. Prefer `original_message_id`, which is always present.
        </ResponseField>

        </ResponseField>

          </Expandable>

        <ResponseField name="selected_id" type="string" required>

        <ResponseField name="selected_display_text" type="string" required>
          Text of the selected button
        </ResponseField>

          Button index (0-based)
        </ResponseField>
        <ResponseField name="quoted_message_id" type="string" required>
          ID of the message containing the buttons
        </ResponseField>
      </Expandable>
      <Expandable title="ListData (type=list)">
        <ResponseField name="title" type="string" required>
          List title
        </ResponseField>
        <ResponseField name="description" type="string">
          Message description/body
        </ResponseField>
        <ResponseField name="button_text" type="string" required>

        </ResponseField>
        <ResponseField name="footer_text" type="string">
          Footer text
        </ResponseField>
        <ResponseField name="list_type" type="number" required>
          List type
        </ResponseField>
        <ResponseField name="sections" type="array" required>

            <ResponseField name="title" type="string">Section title</ResponseField>
            <ResponseField name="rows" type="array">
              <Expandable title="Row">
                <ResponseField name="row_id" type="string">Option ID</ResponseField>
                <ResponseField name="title" type="string">Option title</ResponseField>
                <ResponseField name="description" type="string">Option description</ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
      <Expandable title="CarouselData (type=carousel)">
        <ResponseField name="type" type="string" required>

        </ResponseField>
        <ResponseField name="cards" type="array" required>
          <Expandable title="Card">
            <ResponseField name="header_title" type="string">Card title</ResponseField>
            <ResponseField name="body" type="string">Card body</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>

        <ResponseField name="type" type="string" required>

        <ResponseField name="header_title" type="string">
          Header title
        </ResponseField>
        <ResponseField name="header_subtitle" type="string">
          Header subtitle
        </ResponseField>
        <ResponseField name="header_has_media_attachment" type="boolean">

        </ResponseField>
        <ResponseField name="body" type="string">
          Message body

        <ResponseField name="footer" type="string">
          Footer text

          <Expandable title="Button">

          </Expandable>

          CTWA source app (e.g. `facebook`)

        </ResponseField>
        <ResponseField name="title" type="string" required>

        </ResponseField>

          Click ID for attribution
        </ResponseField>
        <ResponseField name="source_id" type="string" required>
          Ad ID
        </ResponseField>
        <ResponseField name="source_type" type="string" required>
          Type (e.g. `ad`)
        </ResponseField>
        <ResponseField name="source_url" type="string" required>

        </ResponseField>

        <ResponseField name="media_url" type="string" required>
          Ad media URL
        </ResponseField>
        <ResponseField name="thumbnail_url" type="string" required>
          Thumbnail URL
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

When someone edits a message that was already sent, WhatsApp does not update the original
message: it sends a new event. That is why the edit arrives as a regular
`messages.received`, with `type: "edited_message"`.

`data.id` is the ID **of the edit event**. The message that was edited is in
`data.data.original_message_id` — use it to update the record in your
database.

Media caption edits (image, video, document) also arrive here,
with the new caption in `message`.

## Identifying types

| Condition | Type |
|----------|------|
| `data.type === "text"` | Text message |
| `data.type === "image"` | Image |
| `data.type === "video"` | Video |
| `data.type === "audio"` | Audio/PTT |
| `data.type === "document"` | Document |
| `data.type === "sticker"` | Sticker |
| `data.type === "contact"` | Contact |
| `data.type === "location"` | Location |
| `data.type === "reaction"` | Reaction |
| `data.type === "poll_update"` | Poll update |
| `data.type === "list_response"` | Interactive list reply |
| `data.type === "template_button_reply"` | Button click |
| `data.type === "list"` | Interactive list message |
| `data.type === "carousel"` | Card carousel |
| `data.type === "nativeflow"` | Message with buttons (quick_reply/cta_url) |
| `data.context_info?.quoted_message` | Is a reply |
| `data.context_info?.entry_point_conversion_source === "ctwa_ad"` | Came from an ad |

## Media URLs

Media files are automatically saved to S3 and made available in `data.media_url`.

| Type | Extension | Example |
|------|----------|---------|
| image | .jpg, .png | `https://s3.../image/{id}.jpg` |
| video | .mp4 | `https://s3.../video/{id}.mp4` |
| audio | .ogg | `https://s3.../audio/{id}.ogg` |
| document | .pdf, .docx | `https://s3.../application/{id}.pdf` |
| sticker | .webp | `https://s3.../image/{id}.webp` |
