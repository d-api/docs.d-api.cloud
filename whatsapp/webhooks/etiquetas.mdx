---
title: "Eventos de etiquetas"
description: "Etiquetas (Listas do WhatsApp) criadas, editadas e aplicadas a conversas e mensagens."
---

O WhatsApp organiza conversas em **etiquetas**, que nas versões recentes do app
aparecem como **Listas**. Estes webhooks notificam quando uma etiqueta é criada,
editada ou excluída, e quando ela é aplicada ou removida de uma conversa ou de
uma mensagem.

Todos seguem o [envelope comum](/whatsapp/webhooks/visao-geral) — o conteúdo
específico fica em `data`.

| Evento | Quando |
|--------|--------|
| `labels.edit` | Etiqueta criada, editada ou excluída |
| `labels.association.chat` | Etiqueta aplicada ou removida de uma conversa |
| `labels.association.message` | Etiqueta aplicada ou removida de uma mensagem |

<Note>
  Os webhooks entregam **mudanças**. Ao conectar, a sessão sincroniza todas as
  etiquetas e associações da conta, mas essa sincronização não gera webhooks
  (seria o mesmo estado reenviado a cada reconexão). Para o estado completo, use
  `GET /labels/list` e `GET /labels/contact-labels`.
</Note>

## `labels.edit`

```json
{
  "event": "labels.edit",
  "sessionId": "minha-sessao",
  "timestamp": "2026-09-30T16:30:00.000Z",
  "data": {
    "label_id": "25",
    "name": "MQL SaaS",
    "color": 3,
    "deleted": false,
    "list_type": "custom",
    "predefined_id": 0,
    "order_index": 12,
    "is_active": true,
    "is_immutable": false,
    "from_full_sync": false,
    "ts": 1790786186704
  }
}
```

<ResponseField name="label_id" type="string" required>
  Identificador da etiqueta.
</ResponseField>

<ResponseField name="name" type="string">
  Nome da etiqueta.
</ResponseField>

<ResponseField name="color" type="number">
  Código de cor da etiqueta.
</ResponseField>

<ResponseField name="deleted" type="boolean">
  `true` quando a etiqueta foi **excluída**.
</ResponseField>

<ResponseField name="list_type" type="string">
  Tipo da lista. `custom` para as criadas pelo usuário; as listas do próprio
  WhatsApp vêm como `unread` (Não lidas), `favorites` (Favoritos), `groups`
  (Grupos), `predefined` (sugeridas pelo app, como "Novo pedido"), entre outras.
  Etiquetas antigas podem vir como `none`.
</ResponseField>

<ResponseField name="predefined_id" type="number">
  Identificador da lista sugerida pelo WhatsApp, quando `list_type` é
  `predefined`. `0` nas demais.
</ResponseField>

<ResponseField name="order_index" type="number">
  Posição da lista no app.
</ResponseField>

<ResponseField name="is_active" type="boolean">
  Se a lista está ativa no app.
</ResponseField>

<ResponseField name="is_immutable" type="boolean">
  `true` para listas do sistema, que o usuário não pode renomear nem excluir.
</ResponseField>

<ResponseField name="ts" type="number">
  Momento do evento em milissegundos (epoch).
</ResponseField>

## `labels.association.chat`

```json
{
  "event": "labels.association.chat",
  "sessionId": "minha-sessao",
  "timestamp": "2026-09-30T16:36:26.764Z",
  "data": {
    "label_id": "25",
    "label_name": "MQL SaaS",
    "label_color": 3,
    "chat": "558597673993@s.whatsapp.net",
    "labeled": true,
    "from_full_sync": false,
    "ts": 1790786186704
  }
}
```

<ResponseField name="label_id" type="string" required>
  Identificador da etiqueta.
</ResponseField>

<ResponseField name="label_name" type="string | null">
  Nome da etiqueta. `null` se ela ainda não foi sincronizada.
</ResponseField>

<ResponseField name="label_color" type="number | null">
  Cor da etiqueta. `null` se ela ainda não foi sincronizada.
</ResponseField>

<ResponseField name="chat" type="string" required>
  JID da conversa (`...@s.whatsapp.net` ou `...@g.us`). Quando o número do
  contato não é conhecido pela sessão, vem como LID (`...@lid`).
</ResponseField>

<ResponseField name="labeled" type="boolean" required>
  `true` aplica a etiqueta à conversa; `false` remove.
</ResponseField>

## `labels.association.message`

Mesmos campos de [`labels.association.chat`](#labels-association-chat), mais o
identificador da mensagem.

```json
{
  "event": "labels.association.message",
  "sessionId": "minha-sessao",
  "timestamp": "2026-09-30T16:40:00.000Z",
  "data": {
    "label_id": "25",
    "label_name": "MQL SaaS",
    "label_color": 3,
    "chat": "558597673993@s.whatsapp.net",
    "message_id": "3EB0F61B5D1F94FAFCD306",
    "labeled": true,
    "from_full_sync": false,
    "ts": 1790786400000
  }
}
```

<ResponseField name="message_id" type="string" required>
  Identificador da mensagem.
</ResponseField>
